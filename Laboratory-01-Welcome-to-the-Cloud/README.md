## 🎯 Mission Overview
This activity onboarded me as a Junior Cloud Infrastructure Engineer Trainee. I learned to work inside a Linux environment using KillerCoda, gather system information, organize files and directories, and build a version-controlled portfolio on GitHub.

## 🧭 Objectives
- [x] Access a cloud-based Linux environment using KillerCoda
- [x] Explore and navigate the Linux operating system
- [x] Gather basic system information
- [x] Organize files and directories using Linux commands
- [x] Create and maintain a professional GitHub repository
- [x] Document technical work using Markdown

## 🛠️ Activities Performed
1. Launched an Ubuntu Linux Playground on KillerCoda and verified the terminal was working
2. Created a new user (`vventura`) with a home directory and sudo privileges, then logged in
3. Recorded username, working directory, and hostname; captured terminal screenshot
4. Investigated the Linux environment (distro, kernel, CPU, memory, disk) and recorded findings
5. Created the `Documents`, `Notes`, `Reports`, `Screenshots` folders and an `about-me.md` note
6. Built the GitHub portfolio repository and folder structure
7. Documented the mission and captured evidence screenshots
8. Reviewed, committed, and pushed the final repository

## 💻 Linux Commands Used
| Command | Purpose |
|---|---|
| `sudo adduser` | Create a new user |
| `sudo usermod -aG sudo` | Grant sudo privileges |
| `su -` | Switch user with full login shell |
| `whoami` / `pwd` / `hostname` | Show username, directory, hostname |
| `lsb_release -a`, `uname -r`, `lscpu`, `free -h`, `df -h` | Gather system information |
| `mkdir` | Create directories |
| `nano` | Create/edit Markdown files |
| `ls` / `cat` | List/view file contents |
