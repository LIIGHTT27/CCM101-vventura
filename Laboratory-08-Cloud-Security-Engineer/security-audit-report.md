# Checkpoint 2 – Research: Security Best Practices

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their tasks. This is important in cloud accounts because it helps prevent unauthorized access and reduces damage if an account gets hacked.

## 2. Attack Surface

An attack surface refers to all the possible ways an attacker can access or attack a virtual machine (VM). Examples include open ports, running services, software, and user accounts. Reducing unnecessary access points makes the VM more secure.

## 3. Default Deny Policy

A Default Deny Policy means blocking all network traffic unless it is specifically allowed. It is safer because it prevents unknown and unauthorized connections instead of only blocking known hackers. This helps protect the server from unexpected threats.
