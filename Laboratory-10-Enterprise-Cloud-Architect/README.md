# Mission Overview
The mission did not provide detailed, step-by-step instructions. Instead, the task was to independently design and develop a complete, production-ready infrastructure from the ground up. The finished system was expected to be fully functional, ready for deployment, and suitable for presentation.

This required building the entire environment within a virtual machine, including container management, security configurations, and automation. All planning, implementation, and configuration tasks were handled independently by our team.

# Objectives
- Design and plan a suitable cloud infrastructure.
- Set up and configure a headless Ubuntu Server virtual machine.
- Install and properly configure Docker.
- Independently deploy multiple containerized applications while ensuring persistent data storage through volumes.
- Apply appropriate security measures and configure network port access.
- Automate maintenance and operational processes using cron jobs and Bash scripts.
- Compile and organize all technical documentation into a GitHub portfolio.
- Present, demonstrate, and explain the implemented infrastructure.

# Skills Learned
Through this activity, I gained a better understanding of the proper procedures involved in building and managing server infrastructure. Although I had previously performed some of these tasks, this experience helped me understand the overall process and how to carry out each step more consistently and independently. I also recognized areas where I could further improve my technical skills. Overall, I am satisfied with what I learned from this subject and appreciate the practical experience it provided in developing and managing a working infrastructure.
