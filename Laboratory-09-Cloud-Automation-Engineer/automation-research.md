# Automation Research

## Bash Script

A Bash script is a file that contains Linux commands that run automatically one after another. It helps users perform tasks without typing every command manually. The `#!/bin/bash` line tells the computer to use Bash to run the script.

## Variables

Variables are used to store information such as folder names or file paths. For example, `$BACKUP_DIR` stores the location of the backup folder, so we do not need to type the full path every time. It also makes the script easier to update and manage.

## Cron Job

A cron job is a task in Linux that runs automatically at a scheduled time or date. It is useful in cloud operations because it can perform regular tasks like backups and system updates without someone doing them manually. It saves time and helps prevent forgetting important tasks.
